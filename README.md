# StepWrite｜學測英文作文工作坊

一個可以直接在瀏覽器使用的互動式英文作文鷹架。學生先看懂文章骨架，再跟著提示寫一次，最後用歷屆題目獨立練習。

## 三層學習設計

1. 先學架構：用 111 年公園題依序理解漢堡圖解、文字架構、兩段轉折詞、關鍵字與基礎句。
2. 跟著寫：在六步工作桌中完成自己的兩段作文。
3. 歷屆練習：將相同寫法套用到 113 年、115 年模擬考與 115 年預測題。

完整範文與進階句預設收起，學生完成自己的架構後才主動展開對照。

## 學習流程

1. 拆解題目：先確認兩段各自的任務。
2. 收集素材：用關鍵字記錄觀察、立場、理由與例子。
3. 寫第一段：依序完成總述、圖片 A、圖片 B 與核心差異。
4. 寫第二段：用「立場、理由、具體化」展開觀點。
5. 升級表達：檢查連接詞、細節與句型變化。
6. 完成全文：自動組合兩段草稿並檢查字數、段落與提示框。

## 功能

- 逐步寫作導引，不必面對空白頁一次完成全文
- 依題目逐步帶入任務與關鍵字提示，不直接載入完整答案
- 依學生素材產生可修改的基本句
- 自動保存本機進度
- 即時組稿、字數與結構檢查
- 漢堡寫作圖解與兩段式結構速查
- 10 類轉折詞工具，包含用途、例句與誤用提醒
- 111、113、115 模擬考及 115 預測題練習
- 手機、平板與桌面版響應式介面

直接開啟 `index.html` 即可使用，不需要安裝套件或啟動伺服器。
